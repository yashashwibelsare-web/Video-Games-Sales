Video Game Sales Analysis

## About the Project
Video Game Sales Analysis is a Python-based data analytics project that focuses on understanding video game sales across different platforms, genres, publishers, and regions. In this project, I analyzed video game sales data to identify best-selling games, explore popular gaming genres, compare platform performance, and understand regional gaming preferences. The main purpose of this project is to discover useful insights from sales data using Python and data visualization techniques.

## Project Objectives
The main objective of this project is to analyze video game sales and understand how sales performance changes across different platforms, genres, publishers, and regions. It aims to identify the top-selling games globally and regionally, find the platforms and genres with the highest sales, explore sales trends over different years, and compare publisher performance across different markets.

## Dataset Description
The dataset contains information about video games, including their names, platforms, release years, genres, publishers, and sales figures. It includes regional sales data for North America, Europe, Japan, and other regions, along with total global sales. These columns help in comparing game performance and understanding differences in sales across markets.

## Tools and Technologies Used
This project was completed using Python in Jupyter Notebook. I used Pandas for data handling, cleaning, grouping, and analysis, and Seaborn and Matplotlib for creating visualizations such as bar charts, histograms, box plots, and stacked bar charts.

## Data Analysis Performed
During this project, I checked missing values and explored the dataset using descriptive statistics. I analyzed the top-selling games using global sales figures and calculated total global sales. I compared sales across different gaming platforms and genres using grouping and aggregation techniques. I also explored yearly sales trends, analyzed publisher performance, and compared sales across North America, Europe, Japan, and other regions. Visualizations were used to make the results easier to understand and compare.

## Key Learning Outcomes
Through this project, I improved my understanding of data cleaning, exploratory data analysis (EDA), Pandas functions, groupby operations, sorting, aggregation, and data visualization. I also learned how to analyze real-world sales data and present meaningful insights through graphs and charts.

## Conclusion
This project helped me understand how Python can be used to analyze video game sales data and identify patterns in the gaming market. By comparing global and regional sales, platforms, genres, publishers, and yearly trends, the analysis provides a clearer view of video game sales performance. It also strengthened my practical skills in Python and data analytics.
